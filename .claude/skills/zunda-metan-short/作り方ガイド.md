# ずんだもん＋四国めたん 掛け合いショートの作り方ガイド

四国めたんが悩みを出し、ずんだもんが答える掛け合い形式の縦型ショート（1080×1920・60〜75秒）を、Remotion で作るための手順書です。
これまでに作った「いま契約すべきAI【目的別3選】」「Orca を1分で解説」と同じ作り方・同じテイストで、何本でも作れるようにしてあります。

---

## いちばん簡単な使い方（Claude Code に頼む）

このリポジトリ（`7guitai/Remotion-edit`）を開いた Claude Code で、次のように頼むだけです。
`.claude/skills/zunda-metan-short/` にこの手順がスキルとして入っているので、Claude が自動で読み込んで同じ形式で作ります。

```
いつもの、ずんだもんとめたんの掛け合いショートで「〇〇」を解説する動画を作って。
デザインは同じテイストで、配色や図解でオリジナリティを出して。タイトルと概要欄も作って。
```

新しい環境（新しいセッション）では、最初に立ち絵の zip（坂本アヒルさんの PSD 2つ）をアップロードしてください。立ち絵のパーツは Git に入れていないためです。

## 自分で作る場合の手順

### 0. 初回だけ

```bash
npm install
pip install psd-tools
python3 scripts/export_psd_parts.py ずんだもん立ち絵素材2.3.zip 四国めたん立ち絵素材2.1.zip
```

### 1. ひな形から新しいショートを作る

```bash
python3 scripts/new_short.py notebooklm      # 例：src/shorts/notebooklm/ ができ、notebooklm-short として登録される
npx remotion studio                         # すぐにプレビューできる（音声はまだ無し）
```

### 2. 台本を書く（`src/shorts/<id>/script.json`）

おすすめの構成（60〜75秒、18〜23セリフ）：

1. **つかみ**：めたん「〇〇で困ってない？」→ ずんだもん「〇〇なら一発なのだ！」
2. **悩み**：お金・時間・手間など、不満を具体的に
3. **〇〇とは**：一言で正体＋事実3つ
4. **特徴 3〜5個**：ずんだもんが説明 → めたんが反応（「それは便利ね」「〜ってこと？」）
5. **向き不向き**：めたん「誰にでも必要なわけじゃないわよね」→ ずんだもん「〇〇な人向けなのだ」
6. **まとめ**：結論＋「保存して、あとで見返すのだ！」

- `text` は画面のテロップ（`\n` で改行、1行16文字前後）。`speech` は読み上げ用で、英語はカタカナにします（Claude Code →「クロードコード」）。
- 表情 `face`：ずんだもん `normal` / `explain` / `happy`、めたん `normal` / `think` / `happy`。

### 3. 音声を作る（VOICEVOX）

```bash
# VOICEVOX アプリを起動しておく
python3 scripts/generate_short_voice.py <id>
```

ずんだもん・四国めたんの声で、セリフごとの wav と、長さ・口パク用データが作られます。尺は音声の長さで自動的に決まります。

### 4. 素材をそろえる

- **BGM**：`script.json` の `bgm` に甘茶の音楽工房の曲を書いて `python3 scripts/download_short_assets.py <id>`
- **公式サイトの画面**：撮影して `public/shorts/<id>/shots/` に置く（`scripts/capture_pricing.js` が例）
- **デモ動画・画像**：`public/shorts/<id>/media/` に置く（OSS なら公式リポジトリの素材。ライセンスを確認）
- **ロゴ**：Simple Icons の SVG を `public/shorts/common/icons/` に追加

### 5. 画面を作り込む

- `theme.ts` の配色 `C` を題材に合わせて変える（毎回変えてオリジナリティを出す）
- `scenes.tsx` に、題材に合ったシーン（比較表・デモ画面・フロー図など）を足す
- 静止画で確認しながら直す：`npx remotion still <id>-short out/check.png --frame=300 --scale=0.4`

### 6. 書き出す

```bash
npx remotion render <id>-short out/raw.mp4
ffmpeg -i out/raw.mp4 -c:v copy -af loudnorm=I=-14:TP=-1.5:LRA=11 -c:a aac -b:a 192k out/<id>-short.mp4
```

### 7. タイトルと概要欄

`src/shorts/<id>/description.txt` のひな形を埋めます。クレジットの `VOICEVOX:ずんだもん` `VOICEVOX:四国めたん` は**必須**です。

## デザインのルール（同じテイストを保つために）

| 場所（縦 1920px） | 置くもの |
| --- | --- |
| 上 112〜330 | 白い帯のヘッダー（タイトル＋ラベル／章の進行） |
| 中 360〜1060 | 白いカード・実際の画面・図解 |
| 1100〜1350 | 暗色の角丸テロップ枠＋左上に話者名 |
| 下 1300〜 | 左にめたん、右にずんだもん（小さめの全身、口パク・まばたき・表情差分） |

- 明るい背景＋白いカード＋暗色テロップ。フォントは Noto Sans JP の太字だけ。
- BGM は小さめ（0.07）で、セリフの間はさらに自動で下げる（`ShortAudio`）。
- テロップの大事な言葉は `{ }` で囲んで色を付ける。セリフに `"mark": "!"` などで感情マーク。
- シーンの切り替えにワイプや「シュッ」という音は入れない（くどくなるため）。公式のデモ動画や画面があれば必ず使う。
- 配色は白ベース＋淡い色（例：白×薄い緑）。
- 縁取り文字・ネオン・派手なスタンプは使わない（チープに見えるため）。
- 実際の画面はブラウザ枠・アプリ枠に入れて、該当箇所にズーム＋枠で強調する。
- 料金・数値は公式で確認し、「〇年〇月時点」を入れる。説明用の図には「イメージ」と書く。

## 権利まわり

| 素材 | 注意 |
| --- | --- |
| 音声（VOICEVOX） | 概要欄に `VOICEVOX:ずんだもん` `VOICEVOX:四国めたん` が必須 |
| 立ち絵（坂本アヒルさん） | 商用・改変可（公式ガイドライン準拠）。クレジット任意。Git には入れない |
| BGM（甘茶の音楽工房） | 商用可・クレジット任意。再配布不可・Content ID 登録不可。Git には入れない |
| 他社のロゴ・画面 | 紹介・解説の範囲で使う。画面の中身は加工しない |
