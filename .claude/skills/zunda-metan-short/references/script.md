# 台本（script.json）の書き方

## 構成（60〜75秒・18〜23セリフが目安）

| シーン | 内容 | 例 |
| --- | --- | --- |
| つかみ | めたんが悩み → ずんだもんが一言で答え | 「〇〇、1つずつ待ってない？」「〇〇なら同時に動かせるのだ！」 |
| 悩み | 不満を具体的に（お金・時間・手間） | 「全部入れたら月9,000円超え」「ターミナルが散らかる」 |
| 〇〇とは | 一言で正体＋事実3つ | 「無料のオープンソースアプリなのだ」 |
| 特徴 ×3〜5 | 1特徴＝ずんだもんの説明＋めたんの反応 | 「お互いの変更がぶつからないのね」 |
| 注意点・向き不向き | めたん「誰にでも必要なわけじゃないわよね」 | 「たまに使うだけなら今のままでOK」 |
| まとめ | 結論＋「保存して〜」 | 「保存して、あとで試すのだ！」 |

## セリフのルール

- `text`＝画面のテロップ（`\n` で改行、1行 16 文字前後まで。2行が基本、最大3行）。
- `speech`＝読み上げ文。英語・記号は**カタカナにする**（Orca→オルカ、Claude Code→クロードコード、AI→エーアイ、ChatGPT→チャットジーピーティー）。数字はそのままでよい（3000円→さんぜんえん）。
- `face`：ずんだもん `normal` / `explain`（指差し）/ `happy`（にっこり・手を挙げる）、めたん `normal` / `think`（口元に指・困り眉）/ `happy`（目を閉じて笑う・指差し）。表情とポーズは `src/shorts/common/characters.json` で増やせる。
- めたんの疑問 → ずんだもんの答え、のテンポを崩さない。1セリフは長くても 5〜6 秒。
- シーンには `type`（`scenes.tsx` のどの部品で描くか）と `chapter`（ヘッダーの章表示）を必ず付ける。その他のキー（`points`・`video` など）は自由に足してよい。

## 例（一部）

```json
{
  "type": "feature",
  "chapter": "機能",
  "no": 1,
  "title": "並列ワークツリー",
  "video": "parallel-worktrees",
  "points": ["作業ごとに独立したgitワークツリー", "エージェントを横に並べて同時進行", "変更どうしがぶつからない"],
  "lines": [
    { "who": "zundamon", "face": "explain", "text": "作業ごとにワークツリーを分けて\nエージェントを並べて走らせられるのだ", "speech": "作業ごとにワークツリーを分けて、エージェントを並べて走らせられるのだ。" },
    { "who": "metan", "face": "happy", "text": "お互いの変更が\nぶつからないのね", "speech": "お互いの変更が、ぶつからないのね。" }
  ]
}
```
