# 画面の作り方

## 画面の割り付け（1080×1920）

| 範囲（y） | 置くもの |
| --- | --- |
| 0〜110 | 何も置かない（スマホのステータスバー・Shorts の上部 UI） |
| 112〜330 | ヘッダー：白い半透明の帯。小見出し＋タイトル（60px 前後）＋ラベル or 章の進行 |
| 360〜1060 | ステージ：シーンの中身（幅 1000px のカード・画面・図解） |
| 1100〜1350 | テロップ：暗色の角丸枠＋左上に話者名ラベル（`common/Subtitle.tsx`） |
| 1300〜1985 | 立ち絵：めたん左（x=150）、ずんだもん右（x=935・左右反転）、足元は少し画面外 |

Shorts の右側（いいね等のボタン）と下部（タイトル・チャンネル名）は UI に隠れるので、大事な文字は置かない。

## 共通テイスト

- 背景は明るく（薄いグレー〜水色のグラデーション）。公式画面を大きくぼかして敷くと情報系らしくなる。
- 情報は白いカード（角丸 26px・柔らかい影 `SHADOW`）。強調だけ暗色パネル。
- フォントは Noto Sans JP の Black（900）と Bold（700）だけ。縁取り文字・ネオン・派手なスタンプは使わない（チープに見える）。
- 実際の画面は「ブラウザ枠」や「アプリ枠」に入れ、該当箇所へゆっくりズーム＋枠で強調（`ai-subscription/parts.tsx` の `ShotFrame`、`orca/AppWindow.tsx`）。
- 効果音は控えめ（pop 0.2〜0.3、whoosh 0.3、ding 0.35）。BGM 0.11〜0.13。

## 動画ごとに変えるところ（オリジナリティ）

- `theme.ts` の配色（例：AIサブスク＝赤×茶、Orca＝紺×水色の「氷の海」）。
- ヘッダーの形（アイコンの有無、ラベル、章の進行表示など）、テロップ枠の飾り（左ライン・名前タブの形）。
- 背景の模様（ストライプ、波、ぼかし画像）。
- 題材に合う図解：比較なら明細・表、ツールならデモ動画・フロー図・アイコン一覧、手順ならステップ表示。

## 作り込みのコツ

- アニメーションはセリフに合わせる：`scene.lines[1].from` で2つ目のセリフの頭、要点は `lines[0].from + 10` から等間隔に出す。
- `useRise`（下からふわっと）、`useSpring`、`Sfx` は `src/shorts/common/parts.tsx`。
- 長い文字は `whiteSpace: "nowrap"` にして、はみ出したら文字を小さくするか文言を短くする。
- **必ず静止画で確認**：`npx remotion still <id>-short out.png --frame=<n> --scale=0.4` を各シーン1枚ずつ書き出し、数枚を横に並べて見る。テロップとカードの重なり、カードからのはみ出し、折り返しを直す。
