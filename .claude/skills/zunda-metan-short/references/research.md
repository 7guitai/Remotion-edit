# 題材の調べ方

- 名前が同じ別サービスが多い（例：「Orca」は複数ある）。チャンネルの傾向（AIツール解説）から一番ありそうなものを選び、前提をユーザーに一言伝える。
- **一次情報を優先**：公式サイト、公式の料金ページ、公式 GitHub の README・リリース。比較記事は目安にとどめ、数字は公式で裏を取る。
- 料金は国で表示通貨が変わる。日本向けの動画では日本の公式ページ（例：Google One は `?hl=ja&gl=JP`）を確認する。確認できない値は「約」「目安」と書く。
- オープンソースのツールなら、リポジトリを clone して README・LICENSE・`docs/assets` を読む。デモ用の画像やアニメーションがあれば素材に使える（ライセンス確認）。
- メモする項目：何ができるか（3〜5個）／料金と無料範囲／対応環境／誰に向いているか・向いていないか／注意点（別途費用など）／公式リンク。
