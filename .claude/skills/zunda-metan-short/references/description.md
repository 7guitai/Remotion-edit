# タイトルと概要欄

`src/shorts/<id>/description.txt` に書く（ひな形あり）。

- **タイトル**：30〜40 字。具体名＋数字＋ベネフィット。【2026年11月】【無料】などの括弧で補足。候補を 2〜3 個出す。
- **概要欄**：
  1. 1〜2 文で「誰向けに何がわかるか」
  2. ▼ 結論／できること（箇条書き）
  3. ▼ リンク・出典（公式サイト・料金ページ・GitHub）
  4. ※ 時点・料金・注意書き（別途費用など）
  5. ▼ クレジット（`VOICEVOX:ずんだもん` `VOICEVOX:四国めたん` は必須、立ち絵・BGM・素材）
  6. ハッシュタグ 6〜8 個（`#ずんだもん #Shorts` を含む）
- ショートでは概要欄のチャプター（タイムスタンプ）は表示されないので入れない。
- アフィリエイトや提供がある場合は、タイトルか冒頭に【PR】、画面にも「PR」表記を入れる。
