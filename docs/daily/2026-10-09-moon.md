# もし地球の重力が月と同じになったら？

参考動画に合わせた、黒背景・黄色と赤の見出し・中央の3D物理シミュレーション・大きな白字幕の縦型ショート。1080×1920、30fps、約38秒。

赤：地球の重力。青：月と同じ約6分の1の重力。人形はcannon-esの関節付きラグドールで計算。質量は固定し、重力のみ変更。空気抵抗は省略。実測値や現実の月面環境の完全な再現ではない。

## 再現

```bash
npm ci
python3 -m pip install numpy

# 音声は同梱。再生成する場合はVOICEVOXを起動

npx remotion render whatif-moon-gravity-2026-10-09 out/whatif-moon-gravity-2026-10-09.mp4 --gl=swangle --crf=25

```

## 確認

- 型チェック成功、各シーンの静止画を目視確認。
- シミュレーションの全座標が有限値であることを確認。
- 低重力でも空中で再ジャンプしないよう、繰り返しジャンプを着地後に限定。
- 高いジャンプや遠いボールが画面外へ出ないよう、低重力のカメラを調整。
- 数値は物理計算結果を表示。ボールの距離を上部でも比較表示。
- 読みの確認を行い、「六分の一」を「ろくぶんのいち」と指定。
- 月の重力についてNASA Moon Factsを参照。
