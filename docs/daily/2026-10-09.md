# 2026-10-09の2ch風ショート

タイトル：【2ch風】サブスク整理したら、使ってない課金が出てきた

1080×1920 / 30fps / 約44.2秒。実在のスレッドを転載しないオリジナル創作。
月980円×3契約×12か月＝35,280円の架空の例。

制作ガイドはルートの [agent.md](../../agent.md)。

## 再現

```bash
npm ci
python3 scripts/make_daily_bgm.py
# 音声は同梱。再生成する場合、VOICEVOXを起動してから以下を実行
python3 scripts/generate_voice.py subscription-2ch-2026-10-09 --engine voicevox
npm run lint
npx remotion render subscription-2ch-2026-10-09 out/subscription-2ch-2026-10-09.mp4 --crf=24
python3 scripts/make_description.py subscription-2ch-2026-10-09
```

Linuxで既存Chromiumを使う場合は、レンダリングに `--browser-executable=/usr/bin/chromium` を追加する。静止画スクリプトには `REMOTION_BROWSER_EXECUTABLE=/usr/bin/chromium` を指定できる。
