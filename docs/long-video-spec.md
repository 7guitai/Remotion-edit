## 3. 台本執筆（ライティング）の7大法則

同チャンネルの3本の動画（[円周率](http://www.youtube.com/watch?v=fPZ7fWDvfjs)、[無限](http://www.youtube.com/watch?v=NgzA0BhOw6M)、[オイラーの等式](http://www.youtube.com/watch?v=fuFQ2parFHU)）に完全共通する、台本執筆のアルゴリズムです。

### 法則①：タイトルと冒頭20秒の「認知的不協和（パラドックス）」設計
- **タイトルの型：** `【〇〇の正体】なぜ[直感に反する現象・命題]なのか？`
  - 例1：[【円周率の正体】なぜπは円のない場所にまで現れるのか](http://www.youtube.com/watch?v=fPZ7fWDvfjs)
  - 例2：[【無限の正体】なぜ"無限より大きい無限"があるのか？](http://www.youtube.com/watch?v=NgzA0BhOw6M)
  - 例3：[【オイラーの等式の正体】なぜ円周率とネイピア数は1つの式で"0"になるのか？](http://www.youtube.com/watch?v=fuFQ2parFHU)
- **冒頭20秒の型：**
  1. **0〜15秒（具体的な操作と奇妙な結果）：** 抽象論ではなく、「床に線を引いて針をまく」「満室のホテルに客が来る」「2つの数を式に入れる」といった具体的なアクションと、その意外な結果を3〜4文で描写する。
  2. **15〜22秒（逆接＋中心的な問い）：** `「それなのに、なぜ〜なのか」「〜なのに、なぜ〜なのだろうか」` と問いを立ててオープニングを締める。

### 法則②：専門用語を「動詞と日常語」に解体する翻訳ルール
数式や定理の名前を先に出すのではなく、**「どんな操作をするとどうなるか」を平易な大和言葉・日常語で描写してから、最後に名前を添える（あるいは名前すら出さない）**のが鉄則です。

| 元の専門用語・概念 | 動画内での実際の翻訳表現（台本抜粋） | 翻訳のメカニズム |
| :--- | :--- | :--- |
| **内接・外接正多角形による近似** | 「円の内側にぴったり入る正六角形を描く」「外側をぴったり囲む正六角形を描く」「この数を挟み撃ちにした」 | 漢字熟語（内接・外接）を「ぴったり入る・囲む」という視覚的な動詞に変換 |
| **リチャードソン補外（加速法）** | 「計算の途中の値から、答えを先回りして当てる工夫をした。多角形を細かくするたびに値が近づいていく、その近づき方の決まりを使ったのだ」 | 手法の名称は一切出さず、「何に着目してどう工夫したか」の仕組みだけを言語化 |
| **互いに素（Coprime）** | 「2つが、1の他に共通の約数を持たない確率」 | 定義そのものを平易な言葉でそのまま言い換える |
| **弾性衝突と運動量保存則** | 「床に摩擦はなく、ぶつかっても勢いは失われないとする」「動きのエネルギーが減らないこと」「重さ×速さの合計が変わらないこと。これを運動量という」 | 物理法則を「減らない」「変わらない」という日常語で表し、後から用語を添える |
| **2次元ガウス分布の等方性** | 「山を1つではなく、横と縦の2方向に並べてみる。横にも縦にも同じばらつきがあると、点は真ん中から見てどの向きにも同じように散らばる。つまり、点は丸く散らばる」 | 数式（$e^{-(x^2+y^2)}$）を一切出さず、「山を2方向に並べる→上から見ると丸く散らばる」と空間イメージで説明 |
| **超越数（Transcendental number）** | 「円周率は、整数を使ったどんな方程式の答えにもならない。こうした数を超越数という」 | 「代数的数でない」という定義を「どんな方程式の答えにもならない」と一発で分かる表現に翻訳 |

### 法則③：一文の長さと「接続詞」による論理ドライブ
- **一文の長さ：** 1センテンスは**20文字〜40文字程度（読み上げ時間で3〜5秒）**で必ず句点「。」を打ちます。
- **論理を前に進めるシグナル接続詞：**
  - **展開・実験：** `「まず〜」「次に〜」「〜してみよう」「〜とする」`
  - **転換・意外性：** `「ところが〜」「けれど〜」「それなのに〜」「実は〜」`
  - **核心・種明かし：** `「つまり〜」「だから〜」「鍵は〜だ」「〜なのだ」`
  - **章の切り替え：** `「では〜」「次は〜だ」「最初の問いに戻ろう」`

### 法則④：具体的な数字のステップアップ（3段階の法則）
視聴者に規則性を納得させる時は、いきなり一般化（$n$倍）せず、**必ず具体的な数字を3〜4段階並べてリズムを作ります**。
> **実際の台本例（[円周率の動画 01:23〜](http://www.youtube.com/watch?v=fPZ7fWDvfjs)）：**  
> 「内側の正12角形の周りは、直径の約3.106倍。角が24なら約3.133倍。48なら約3.139倍。アルキメデスは96角形まで計算した。」
>
> **実際の台本例（[円周率の動画 07:34〜](http://www.youtube.com/watch?v=fPZ7fWDvfjs)）：**  
> 「同じ重さなら、ぶつかる回数は3回。重い箱を100倍の重さにすると31回。1万倍で314回。100万倍で3141回。重さを100倍ずつにするたびに、円周率の数字が1つずつ増えていく。」

### 法則⑤：歴史エピソードは「年代＋場所＋人物＋人間味（ユーモア・執念・皮肉）」
単なる歴史紹介ではなく、思わず誰かに話したくなる「人間ドラマの1行」を必ず挟みます。
- **ニュートン：** 疫病で大学が閉まっていた1666年頃に16桁を計算し、後に「他にすることがなくて、恥ずかしいほどの桁まで計算した」と手紙に書いた。
- **シャンクス：** 何年もかけて707桁を手計算したが、71年後に計算機で確かめると「528桁目から先が間違っていた」と発覚した。
- **ラザリーニ：** 3408本の針を落として小数第6位までピタリと当てたが、「数字ができすぎていたため、答えに合うところで実験を止めたのではないかと疑われている」。
- **インディアナ州議会：** 円周率を事実上3.2とする法案が下院を通ったが、たまたま議会に来ていた数学教授が議員に説明して止められた。

### 法則⑥：クライマックスでの「定義の再構築（本質の一言化）」
終盤のまとめでは、動画の冒頭で出した「教科書の定義」を、動画全体を貫く「新しい本質的な定義」へと書き換えます。
- **円周率の動画：** 「周りの長さ÷直径」 $\longrightarrow$ **「円周率とは、回転の大きさを測る数なのだ」**
- **オイラーの等式の動画：** 「別々の場所で生まれた$e$と$\pi$」 $\longrightarrow$ **「オイラーの等式は、増えることと回ることが同じ1つの計算だと言っている」**

### 法則⑦：エンディングの「未解決の謎」または「読者への静かな問いかけ」
最後は「すべて解明された」で終わらせず、**「ただ、まだ分かっていないこともある」**と現代数学でも未解決のシンプルな問い（円周率の数字の出現割合＝正規数問題、無限の連続体仮説など）を提示し、「今なお続く知のフロンティア」を感じさせて静かにフェードアウトします。

## 4. 映像・アニメーション・音響ディレクション仕様書

動画制作者（モーションデザイナー・編集者・ナレーター）にそのまま渡せる具体的な演出ルールです。

### ① 画面デザイン・ビジュアルスタイル（2Dミニマル・モーショングラフィックス）
- **背景（キャンバス）：**
  - 目が疲れず、図形や数式のコントラストが最も美しく映える**ダークトーン（深いネイビーブラック `#0F141C` 〜 チャコールグレー `#181A20`）**、または落ち着いた羊皮紙・黒板風のマットなテクスチャをベースにします。
- **カラーパレット（意味論的配色）：**
  - 色数を厳格に絞り（1画面に3〜4色まで）、**「色＝意味」**を動画全体で統一します。
  - **ベース色（白・オフホワイト `#F0F4F8`）：** 基準となる図形、軸、基本テキスト、通常の数式。
  - **メインアクセント色（ゴールド／アンバー `#F59E0B` または シアン `#38BDF8`）：** 主役となる概念（この動画では「円」「円周率 $\pi$」「回転の軌跡」）。隠れていた円が浮かび上がる瞬間にこの色を発光させます。
  - **比較・対比色（コーラルレッド `#F43F5E` と エメラルドグリーン `#10B981`）：** 内接多角形と外接多角形、軽い箱と重い箱、足す数と引く数など、2つの要素を対比する時だけ使用します。
- **図形とアニメーションの原則（Show, Don't Just Tell）：**
  - ナレーションで「正六角形を描く」と言ったらその瞬間に線が引かれ、「角の数を12、24、48と倍にしていく」と言ったらリズムに合わせて多角形が滑らかに円へ変形（モーフィング）します。
  - **「種明かし」の視覚効果：** 奇数の足し算、針の落下、箱の衝突グラフ、正規分布の山など、一見「円がない場所」の解説では、まず直線やグラフだけで動きを見せた後、ナレーションの「実は奥に円が隠れている」のタイミングで**背後から半透明の円（または回転する矢印）がスッと重なって現れる演出**を共通フォーマットにします。
- **テキスト・テロップ表示：**
  - フルテロップ（すべての喋り言葉を画面下部に表示するバラエティ風の字幕）は**原則入れない**か、入れるとしても極小・控えめな字幕にとどめます（画面中央の図解アニメーションに100%集中させるため）。
  - 画面内に大きく出す文字は、**「重要な数値（3.1415926...）」「年号と人物名（17世紀 ライプニッツ）」「核となるシンプルな数式」「章のキーワード」**のみを、美しいサンセリフ体または明朝体でミニマルに配置します。

### ② ナレーション・音声・BGM設計
- **ナレーション（声質とテンポ）：**
  - **声質：** 感情を過度に込めず、落ち着いた低〜中音域のクリアな声（知的で信頼感のあるトーン）。
  - **話す速度：** **1分あたり約280〜310文字（1秒あたり約4.8〜5.2文字）**。一般的なYouTube解説動画（1分350〜400文字）よりも**約2割ゆっくり**です。
  - **間（ポーズ）の設計：**
    - 文末の「。」ごとに **0.4〜0.6秒** の明確な間を空けます。
    - 「なぜ〜なのか。」という問いかけの直後や、章が切り替わる箇所では **1.0〜1.5秒** のたっぷりとした「考える余白（間）」を取ります。この「間」が知的な雰囲気を作る最大の秘訣です。
- **BGMと効果音（SE）：**
  - **BGM：** 主張しすぎないアンビエント・ピアノ、ミニマル・クラシック（エリック・サティやマックス・リヒターのような静かな反復音楽）、またはローファイなシンセパッド。音量はナレーションの背後にうっすら敷く程度（-24dB〜-30dB）。
  - **SE（効果音）：** 多用厳禁。図形がピタッと重なる時の微かなクリック音、箱がぶつかる時の澄んだ木琴/金属音、章タイトルが出る時の静かな環境音（ウインドチャイムや低いシンセの余韻）のみに限定します。

## 5. 新規動画制作のための「汎用プロンプト＆構成テンプレート」

別のテーマ（物理、数学、科学、経済、歴史の法則など）でこのチャンネルと全く同じ構成・質感の動画を作るための**8ステップ設計テンプレート**です。

### 【企画・テーマ選定の3条件】
1. **小学生でも知っている言葉や現象**が入り口になっていること（例：円周率、無限、0、素数、重力、確率、時計、カレンダーなど）。
2. **「えっ、なぜそうなるの？」という直感に反する現象（パラドックスや意外な繋がり）**が2つ以上あること。
3. 最終的にそれらの現象が**「たった1つのシンプルな本質（原理）」で鮮やかに一本の線で繋がる**こと。

### 【台本構成シート（10分〜12分動画・約3,200〜3,600文字基準）】

| パート | 目標文字数（目安尺） | 書くべき要素とテンプレート文言 | 映像指示（コンテの型） |
| :--- | :--- | :--- | :--- |
| **1. 導入フック** | 約100〜130字（20〜25秒） | ・挨拶なしでいきなり現象A（0〜8秒）と現象B（8〜16秒）を描写する。<br>・「どこにも〇〇はない。それなのに、なぜ〇〇が現れるのか。」で締める。 | ・現象AとBのシンプルなシミュレーション映像。<br>・最後に中心的な問いのテキストだけを中央に浮かべる。 |
| **2. 基本定義と古代の始まり** | 約150〜200字（30〜40秒） | ・「〇〇とは、〜の数（仕組み）だ。では、〜なのか。」<br>・古代（バビロニア、エジプト、ギリシャ等）の素朴なアプローチを3つ並べる。<br>・「けれど、本当の姿はまだ誰にも分からなかった。」 | ・教科書の定義のシンプルな図解。<br>・年表ではなく、当時の遺物（粘土板や古文書イメージ）と素朴な図形のアニメーション。 |
| **3. 第1章：直感的手法と人類の執念** | 約700〜900字（2分30秒〜3分） | ・最初のブレイクスルー（アルキメデス等の偉人）の手法を手順通りに解説。<br>・現代の身近な例（入試問題や日常の道具）に1つ繋げる。<br>・その手法を極限まで突き詰めた3〜4人の偉人と人間味のある逸話。<br>・「けれど、この方法には限界がある。」 | ・図形が段階的に細かくなり、数値が近づいていくステップアップ表示。<br>・世界の地図や年代とともに桁数・精度が伸びていくインフォグラフィック。 |
| **4. 第2章：視点の転換（数式や別領域への跳躍）** | 約500〜600字（1分45秒〜2分） | ・「〇世紀、全く別の道が見つかった。」<br>・直感とは無関係に見える計算や現象から同じ答えが出る驚きを提示。<br>・計算ミスや手紙の逸話を1つ挟む。<br>・「なぜ〜に〇〇が出てくるのか。実は、奥に〇〇が隠れている。」と種明かし。 | ・数式を視覚的なブロックや波に変換するアニメーション。<br>・式の背後から「隠れていた構造（円や対称性など）」がハイライト色で浮かび上がる。 |
| **5. 第3章：冒頭フック①の回収（意外な領域での出現）** | 約400〜500字（1分30秒） | ・「〇〇の中にも、〜は現れる。」<br>・冒頭で出した現象Aの詳しいルールと答えを提示。<br>・「なぜ〜が関係するのか。つまり〜なのだ。」と直感的な理由を種明かし。<br>・関連する歴史上の実験疑惑やもう1つの派生例を添える。 | ・冒頭の映像を再登場させ、今度はその動きの軌跡に補助線や角度を重ねて「なぜそうなるか」を視覚化する。 |
| **6. 第4章：冒頭フック②の回収（最大の山場）** | 約550〜650字（2分〜2分15秒） | ・「次は、〜だ。」と冒頭の現象B（最も不思議なもの）を取り上げる。<br>・1倍、100倍、1万倍…と条件を変えた時の具体的な数値変化を3〜4段階見せる。<br>・「なぜこんなことが起きるのか。鍵は2つの決まりだ。」<br>・グラフや空間の視点を変えることで、裏に隠れていた本質を鮮やかに見せる。 | ・物理現象のアニメーションと、その横でリアルタイムに連動して描かれるグラフ（位相空間や2次元分布など）。<br>・視点が回転（横から見る→上から見る等）して真相が露わになる3D的な演出。 |
| **7. 第5章：さらなる深み・珍事件・現代の到達点** | 約500〜600字（1分45秒〜2分） | ・その対象のさらなる数学的・科学的性質（証明された限界など）。<br>・歴史上の珍事件・ユーモラスなエピソード（法律や賭けなど）。<br>・現代のコンピュータ記録と、「実際に実用で必要なスケール（NASAや宇宙規模）」の対比。 | ・歴史エピソードのミニマルなアイコン劇。<br>・巨大化する桁数と、宇宙スケールの比較図解。 |
| **8. 結論（本質の再定義）と未解決の余韻** | 約250〜300字（50秒〜1分） | ・これまでの章で登場した具体例を4つほど単語で並べて振り返る。<br>・「〇〇が現れた場所には、いつも『△△』という性質が隠れていた。」<br>・「〇〇とは、△△を測る数（仕組み）なのだ。」（定義のアップデート）<br>・「ただ、まだ分かっていないこともある。〜は今も誰にも証明できていない。」 | ・これまで登場した4つの図解が画面に4分割で並び、すべての中心にある共通の図形（円など）が同時に光る。<br>・最後は静かに数字や図形が流れていき、暗転して終了。 |
