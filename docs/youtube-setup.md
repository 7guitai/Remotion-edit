# YouTube Studio の数字を Claude に読ませる設定（無料）

YouTube Analytics API（Google 公式・無料）を使う。読み取り専用で、動画の投稿や削除はできない。
1日あたりの無料枠（10,000 ユニット）の範囲で足りるので、お金はかからない（クレジットカードの登録も不要）。

取れる数字：再生数、総再生時間、平均視聴時間、平均視聴率（何%まで見られたか）、高評価、コメント、共有、登録者増、**視聴維持率の曲線**。
※ インプレッション数とクリック率（CTR）は、この API では取れない（YouTube Studio の画面でだけ見られる）。

## 1. Google Cloud でプロジェクトを作る（5分）

1. https://console.cloud.google.com/ にチャンネルの Google アカウントでログイン
2. 上の「プロジェクトを選択」→「新しいプロジェクト」→ 名前（例: `yt-analytics`）→ 作成
3. 「API とサービス」→「ライブラリ」で次の2つを検索して「有効にする」
   - **YouTube Analytics API**
   - **YouTube Data API v3**

## 2. OAuth の同意画面（Google Auth Platform）

1. 「API とサービス」→「OAuth 同意画面」→「開始」
2. アプリ名（例: `yt-analytics`）、サポートメール＝自分、対象＝**外部**、連絡先＝自分 → 作成
3. 「対象」→「テストユーザー」に自分の Gmail を追加
4. **「アプリを公開」を押して「本番環境」にする**
   - テストのままだと、取得したトークンが **7日で切れて** 毎週やり直しになる
   - 自分だけで使うので Google の審査は不要。許可の画面で「Google はこのアプリを確認していません」と出たら「詳細」→「（安全ではないページ）に移動」で進む

## 3. OAuth クライアントを作る

1. 「クライアント」→「クライアントを作成」→ アプリケーションの種類＝**デスクトップ アプリ** → 作成
2. 表示された **クライアントID** と **クライアントシークレット** を控える

## 4. 自分のパソコンでトークンを取る（1回だけ）

リポジトリの `scripts/youtube_auth.py` をダウンロードして実行する（Python 3 だけで動く）。

```bash
python3 youtube_auth.py
```

クライアントID とシークレットを入力 → ブラウザで許可 → 最後に3行表示される。

## 5. Claude の環境に入れる

セッション画面のタイトルバーの環境メニュー →「編集」→ 環境変数（または Network secrets / API credentials）に追加：

```
YT_CLIENT_ID=...
YT_CLIENT_SECRET=...
YT_REFRESH_TOKEN=...
```

**チャットには貼らないこと。** 次に始まるセッション（毎日の自動制作を含む）から、
`python3 scripts/youtube_stats.py` で数字を読んで、テーマ選びと改善に使う。
