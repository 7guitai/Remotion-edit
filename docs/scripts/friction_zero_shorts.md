# 「もし摩擦がゼロだったら？」シチュエーション特化版 YouTubeショート台本集（全3本）

**対象チャンネル：** [今から雑学チャンネル（@asmrkids-y4y）](https://www.youtube.com/@asmrkids-y4y)  
**企画背景：** チャンネル内最高再生数を記録した「もし世界から摩擦が突然なくなったら？？」（9,313回再生）の続編シリーズとして、視聴者が自分の日常に当てはめて直感的に楽しめる**「通勤編」「料理編」「スポーツ編」**の3本の秒単位制作台本です。

## バズらせるための共通制作ルール（全台本共通）

| 項目 | 推奨設定・演出のポイント |

## 投稿時の設定・長尺動画への誘導チェックリスト

* **サムネイル（ショート表紙フレーム）の選択：** YouTubeアプリのアップロード画面で、動画内の**「一番カオスに崩壊している瞬間（車が玉突きになっているカットや、人がピンボールのように飛んでいるカット）」**を表紙フレームに指定し、上部に黄色または白赤フチ文字でタイトルを入れてください。
* **関連動画（長尺への誘導）の設定：** YouTube Studioのショート編集画面にある「関連動画」枠に、通常動画の**「もし人間の身長が10cmになったらどうなるのか」**または**「睡眠導入・寝落ち雑学シリーズ」**を必ずリンクさせてください。
* **タイトルの統一感：** 過去のバズ動画（「もし世界から摩擦が突然なくなったら？？」9,313回、「トーストを落とすとバターが下になる？【物理エンジン】」2,002回）と同じく、**「もし〜たら？【物理エンジン】」**のフォーマットに揃えることで、過去動画を見た視聴者のホーム画面（ブラウジング機能・ショートフィード）に再表示されやすくなります。
